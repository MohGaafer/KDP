Amazon KDP iPhone Web App

This is a small installable web app using the original Amazon-hosted Kindle logo artwork, recolored yellow for the icon. The source image is included as icons/kindle-original-amazon.png. It opens a page with a button to Amazon KDP; Amazon's own site remains hosted and controlled by Amazon.

Important limitation: a page hosted on a different domain cannot turn Amazon KDP into an embedded app. Tapping the button navigates to Amazon and iOS may open it in Safari, so the custom icon belongs to the launch page and does not guarantee that KDP stays in standalone app mode.

To install:
1. Upload the contents of this folder to an HTTPS static host such as GitHub Pages.
2. Open the hosted index.html URL in Safari on the iPhone.
3. Tap Share > Add to Home Screen.
4. Keep Open as Web App enabled, edit the name if desired, then tap Add.

Safari reads the site's icon metadata when creating the Home Screen web app.
